# Task 4 - FastAPI Server Initialization

## Introduction
This project demonstrates the development of a REST API using FastAPI and Python. It includes multiple endpoints, JSON request handling, and asynchronous API checks.

## Objectives
- Install and configure FastAPI and Uvicorn.
- Create GET and POST API endpoints.
- Handle JSON request and response data.
- Implement asynchronous functions.
- Execute multiple API checks concurrently.
- Test API functionality using Pytest.

## Technologies and Tools Used
- Python 3.11.9
- FastAPI
- Uvicorn
- Pydantic
- Pytest
- HTTPX
- Visual Studio Code
